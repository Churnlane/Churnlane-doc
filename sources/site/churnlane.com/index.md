The problem

## Churn doesn't start at cancellation.

Long before a customer clicks cancel, they quietly stop showing up. Logins dry up, the main feature goes unused, support tickets go cold. Almost nobody is watching for that — so the first anyone hears about it is the cancellation email.

How much one customer used the product before they cancelled100 = their own normal

Hover the chart to read any day. A typical pattern, not one customer's real data — Churnlane always scores an account against its own history.
